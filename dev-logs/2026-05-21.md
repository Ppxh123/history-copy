## 关键决策

- `better-sqlite3` → `sql.js`（无需 C++ 编译工具）
- npm 脚本通过 `.npmrc` 走 bash，`unset ELECTRON_RUN_AS_NODE` 修复系统环境变量冲突
- 窗口默认隐藏到托盘，点击托盘图标呼出，失焦自动隐藏
- 设置面板从右侧滑入，包含保留天数 + 开机自启

## 打包结果

- [x] **阶段 10：打包测试** — 完成
  - 修复 `electron-builder.yml`：`target: portable` → `target: nsis`（含 NSIS 配置）
  - **winCodeSign symlink 问题**：该工具 7z 包含 macOS dylib 符号链接，Windows Home 无 Developer Mode 无法创建。解决方案：手动预解压到缓存目录 `%LOCALAPPDATA%/electron-builder/Cache/winCodeSign/winCodeSign-2.6.0/`（dylib 占位文件为 0 字节，不影响 Windows 打包）
  - NSIS 安装包成功生成：`release/历史粘贴板 Setup 1.0.0.exe`（82MB）
