## 组件规格

### 标题栏（TitleBar）
- 高度 40px
- 左侧：应用图标 + 应用名称「历史粘贴板」
- 右侧：设置按钮（齿轮图标）、关闭按钮

### 搜索栏（SearchBar）
- 高度 36px
- 圆角 8px
- 背景白色，边框 `#C8DAEA`
- 左侧搜索图标，placeholder "搜索历史记录..."
- 输入时实时筛选

### 历史卡片（HistoryCard）
- 内边距 12px
- 圆角 8px
- 背景白色，边框 `#D6E4F0`
- 悬停背景 `#E8F2FB`
- 左侧：内容预览（文字最多显示 2 行，图片缩略图 48×48）
- 右侧：时间戳 + 操作按钮（置顶、删除）

### 历史列表（HistoryList）
- 虚拟滚动（超过可视区域时复用 DOM 节点）
- 卡片间距 8px
- 置顶项始终在顶部，有分割线区分
- 空状态：居中显示灰色文字「暂无历史记录」

### 设置面板（SettingsPanel）
- 从右侧滑入的侧边面板
- 宽度 300px
- 包含：保留天数选择、开机自启开关
- 底部：数据库路径显示（灰色小字）

## 字体

- 系统默认字体（Windows 11 使用 Microsoft YaHei）
- 文字大小：标题 14px，正文 13px，辅助文字 11px

## 图标

使用简单的 SVG 图标，放在 `assets/icons/` 目录：
- `search.svg` — 搜索
- `pin.svg` / `pin-fill.svg` — 置顶
- `trash.svg` — 删除
- `settings.svg` — 设置
- `close.svg` — 关闭
- `text-icon.svg` — 文字类型标记
- `image-icon.svg` — 图片类型标记
- `copy.svg` — 复制/粘贴
