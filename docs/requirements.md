# 开发需求文档

## 项目概述

一款运行在 Windows 11 上的历史粘贴板管理软件，自动记录用户复制的内容（文字 + 图片），支持查看、搜索、粘贴、置顶和删除。

## 功能需求

### F1. 剪贴板自动监听
- 软件启动后自动在后台监听系统剪贴板变化
- 监听到新内容后自动存入本地数据库
- 支持文字和图片两种类型
- 重复内容不重复记录（哈希去重）

### F2. 历史记录查看
- 点击系统托盘图标打开主面板
- 以卡片形式展示历史记录，按时间降序排列
- 每条卡片显示：内容预览、类型图标、记录时间
- 文字卡片显示文字摘要，图片卡片显示缩略图

### F3. 粘贴功能
- 点击任意历史记录卡片，将该内容恢复到系统剪贴板
- 粘贴后窗口自动隐藏，用户手动 Ctrl+V 完成粘贴

### F4. 置顶功能
- 每条记录可置顶
- 置顶项始终显示在列表最上方
- 置顶项不会被自动清理

### F5. 删除功能
- 每条记录可手动删除
- 删除文字记录同时清除数据库和图片文件

### F6. 搜索功能
- 顶部搜索栏，输入关键词实时筛选
- 仅匹配文字内容，图片不参与搜索
- 搜索结果仍按时间降序

### F7. 存储期限设置
- 提供 1 天 / 3 天 / 5 天选项
- 过期记录自动清理（置顶项除外）
- 默认 3 天

### F8. 记录上限
- 最多保留 500 条记录
- 超过上限时自动删除最旧的非置顶记录

### F9. 系统托盘
- 应用常驻系统托盘，关闭窗口不退出程序
- 右键托盘图标显示菜单：[显示窗口] [退出]
- 左键点击托盘图标呼出面板

### F10. 开机自启
- 默认开启开机自启
- 可在设置中开关

## 非功能需求

- 窗口响应迅速（< 500ms 呼出）
- 图片文件存储在用户 AppData 目录
- 数据库使用 SQLite，文件放在 AppData 目录
- UI 风格简洁直观，主色调淡蓝色
